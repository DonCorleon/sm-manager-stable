{# Loading-state wiring (delegated, attached once). Any form marked data-busy-text="..." disables its submit button and swaps the button text to that string when submitted, so the operator gets immediate visual feedback during slow ops (Steam check, git fetch, etc.). The standard form POST -> redirect cycle re-renders the page on success OR error, so the button comes back fresh either way -- no manual re-enable code needed. We delegate at document level so the dashboard partial swap (every ~5s via SSE) doesn't need to re-attach handlers. #} {# Tooltip wiring. Any element with data-tip="text" gets a tippy popover on hover (desktop) or tap (touch). Cheap to call repeatedly because tippy() is idempotent on already-attached elements when given the same selector. We re-run it after each htmx swap so SSE- refreshed dashboard partials pick up tooltips on newly-rendered elements. #}
